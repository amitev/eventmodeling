# CLI `init` — Requirements

`npx em-cli init` ([SERVER.md](./SERVER.md#2-cli), S2.1, S2.4, S2.14). Code: `cli/init.js`.

- **S2.10** `init`: create `<cwd>/.em/` if missing (S3.1 creates `model/` later), add `.em/.slices` to `<cwd>/.gitignore` unless already ignored (file created if missing), add the Claude permissions (S2.42) to `permissions.allow` in `<cwd>/.claude/settings.json` (created if missing; existing content and entries kept, missing entries appended, invalid JSON fails), print each change made to `.gitignore` or `.claude/settings.json` (nothing when no change is needed), install the packaged skills (S2.11), print the target folder, the package version and removed entries, exit 0. Does not start the server; skips S2.2 and S2.6. Failure: exit 1.
- **S2.11** Packaged skills = every entry of `.claude/skills/` (skill folders and `em-board-api.md`). Copied to `<cwd>/<target>/`; `em-board-api.md` must sit next to the skill folders (skills link `../em-board-api.md`).
- **S2.12** `--target <dir>`: skills folder, relative to `<cwd>`. Default `.claude/skills`. Only with `init`. Empty value: exit 1.
- **S2.13** Reinstall (newer CLI, or any rerun): `<target>/.em-cli.json` (`version`, `entries`) lists the entries installed last. `init` deletes those entries, copies the current ones, rewrites the file. Entries no longer packaged are thus removed. Files not listed (own skills, e.g. generated by `slice-implementation-skill-builder`) are never touched. Local edits to listed entries are overwritten. Entry names with a path separator or `..` in the file are ignored. A target equal to the packaged folder fails (exit 1).
